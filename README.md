# Sales Dashboard Analysis (Power BI)

## 📊 Project Overview
This project analyzes retail sales data using Power BI to uncover insights into sales performance, profitability, and regional trends.

## 📁 Dataset
Superstore dataset containing orders, products, customers, and regional data.

## 📈 KPIs
- Total Sales
- Total Profit
- Profit Margin

## 📊 Dashboard Features
- Interactive filters (Region, Category, Date)
- Drill-down capability
- Sales and profit analysis by category and segment

## 🔍 Key Insights
- Technology generates the highest sales
- Consumer segment dominates purchases
- Profit is concentrated in a few states

## 🛠 Tool Used
- Microsoft Power BI

## 📚 Dataset Source
The Superstore dataset is a publicly available dataset commonly used for learning and practice in data analytics.
